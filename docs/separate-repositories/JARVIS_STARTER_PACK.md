# JARVIS_STARTER_PACK

Status: externalized package.

The Jarvis Starter Pack is no longer maintained inside the `AI-Language-Object` repository.

## Boundary

`AI-Language-Object` keeps:
- AILO language and design specifications
- AILO-N nominal frame layer
- AILO-MCP bridge concepts
- AILO search, logic, TSX, IVK/SEAL reference materials
- historical AILO lineage documents

The separate Jarvis Starter Pack repository/package keeps:
- runnable starter workflows
- Antigravity/Jarvis onboarding material
- IVK runtime utilities
- memory helper scripts
- starter zip/release artifacts
- package-local examples and output paths

## Import Rule

Do not re-add the full starter pack here.

If a starter file becomes language canon, promote only that file into the proper AILO location and register it in `CANON_STATUS.md`.

## Reason

Keeping starter runtime material inside this repository made the AILO language surface harder to navigate and introduced package-local path examples into a public language repository.
