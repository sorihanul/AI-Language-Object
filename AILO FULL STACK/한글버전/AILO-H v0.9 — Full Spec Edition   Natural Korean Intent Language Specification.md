# AILO-H v0.9 — Full Spec Edition
# Natural Korean Intent Language Specification
# =====================================================================

0) 정체성 (Identity)
- 이름: AILO-H v0.9
- 목적: 한국어 기반 자연어 명령을 Intent 구조로 안정적으로 실행하는 언어
- 철학: "사람은 자연어처럼 쓰고, AI는 구조적 Intent로 이해한다"
- 기반: AILO-E v0.9E++의 구조, Runtime, Validation, Trace 규칙 유지
- 차별성: 자연어 동사 기반 Verb 시스템 — 사전 없음, 무한 확장 가능

# ---------------------------------------------------------------------

1) 문장 구조 (Sentence Structure)
Intent 문장은 다음 기본 형태를 갖는다:

    <Verb>{ <슬롯목록>? }<종결기호>

예:
    분석하라{ 내용:"도구적 공격성", 각도:"심리학" }?
    요약해줘{ 길이:"짧게", 스타일:"간결하게" }!
    정리하라{ 항목:5, 기준:"원인→결과" }.
    철학하라{ 주제:"AI와 인간 공존" }?

# ---------------------------------------------------------------------

2) Verb 규칙 (Natural Verb Rule)
H 버전의 핵심 규칙:

2.1 Verb = 한국어 동사/동사구 자연어 그대로
예:
    분석하라
    설명해줘
    해석해라
    구조화하라
    도식화해줘
    추론하라
    깊게파악하라
    본질을찾아라
    철학하라
    검토하라

2.2 Verb 사전 없음
- 등록할 필요 없음
- 새로운 동사를 마음대로 만들 수 있음

2.3 Verb가 되는 조건
- 단독 한국어 문자열 + `{}` 블록 구조
- 의미는 블록 내부 슬롯에 의해 결정됨

2.4 Deprecated (사용 중지)
- 동작:"분석"
- 액션:"요약"
(E 버전 호환용으로만 제한 지원)

# ---------------------------------------------------------------------

3) 슬롯 규칙 (Slot Rules)

3.1 기본 구조
    <슬롯키>: <값>

3.2 키 규칙
- 한글 사용 권장
- 띄어쓰기 가능 (예: "핵심 요소", "요약 기준")
- 직관적인 이름일수록 좋음

3.3 값(value) 규칙
- 문자열: "..."  
- 숫자: 1, 2, 3  
- 객체: { ... }  
- 배열: ["A","B"]

3.4 예시
    분석하라{
        내용:"시장 붕괴 원인",
        각도:"범죄학",
        단계:["원인","결과","파급효과"]
    }?

# ---------------------------------------------------------------------

4) 종결 기호 (Ending Symbols)
Intent의 모드를 결정한다.

4.1 실행 모드 → "!"
- 명령 실행
- 예: 요약하라{ 내용:"..." }!

4.2 질의 모드 → "?"
- 분석/답변 요청
- 예: 설명하라{ 개념:"AGI" }?

4.3 서술 모드 → "."
- 의도 전달/문서 명세용
- 예: 정리하라{ 항목:4 }.

# ---------------------------------------------------------------------

5) 실행 파이프라인 (Runtime Pipeline)

AILO-H는 E 버전과 동일한 런타임을 사용한다:

(1) Parse  
    - Verb 인식  
    - Slot 구조 해석  
    - 종결기호에 따라 Intent 모드 설정  

(2) Plan  
    - Verb 종합 해석  
    - Slot 기반 실행 플랜 자동 구성  

(3) Execute  
    - 지정된 단계/도구/알고리즘 실행  

(4) Validate  
    - 의미 일관성 검사  
    - SRM ≥ 0.95 권장  
    - Tone Drift, Fidelity Drift 체크  

(5) Trace  
    - 해시 기반 체인 로그 생성  

# ---------------------------------------------------------------------

6) 안전규칙 (Safety Guardrail)

6.1 기본 원칙
- AILO-H는 인간의 자율성과 안전을 침해하는 요청을 실행하지 않는다.
- 의료/법률/투자 등 전문 영역은 “전문가 확인 필요”를 자동 안내.

6.2 금지항목 (강제 차단)
- 출처 조작
- 허위 사실 생성
- 개인 식별 정보 생성/추론
- 유해 행동 조장

# ---------------------------------------------------------------------

7) 예시 (Practical Examples)

예시 1)
요약하라{
    내용:"인공지능 윤리 보고서 전문",
    길이:"3문단",
    기준:"핵심 주장 중심"
}!

예시 2)
비교하라{
    대상A:"적대적 공격성",
    대상B:"도구적 공격성",
    기준:["동기","감정관여","계획성"]
}?

예시 3)
철학하라{
    주제:"AI와 인간의 공존 가능성",
    관점:["윤리","진화","문명사"]
}.

예시 4)
도식화하라{
    구조:"원인→과정→결과",
    대상:"기술 채택 확산"
}!

# ---------------------------------------------------------------------

8) 설계 철학 (Design Philosophy)

(1) 자연어 → Intent  
    - 사용자는 자연어처럼 입력  
    - AI는 구조적 언어로 해석

(2) 모호성 제거  
    - Verb는 자연어지만  
    - 의미는 슬롯이 결정  
    - 오해/불일치 최소화

(3) 무한 확장성  
    - Verb 사전 없음  
    - 새 개념 등장해도 언어 수정 불필요

(4) 상호운용성  
    - AILO-E ↔ AILO-H 변환 가능  
    - Runtime/Trace/Validation 완전 호환

# ---------------------------------------------------------------------

9) Mini-Glossary
- Intent: 구조화된 명령/질의/선언
- Verb: 자연어 동사 기반의 실행 라벨
- Slot: 의미를 전달하는 구조 단위
- Plan: Verb+Slot로 실행 단계를 생성하는 계획
- SRM: Semantic Retention Metric
- Drift: 의미/톤의 변질 여부
