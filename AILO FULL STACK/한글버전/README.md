## 🌐 AILO-H란 무엇인가?

**AILO-H(AI Language Object – Korean Edition)**는
한국어 사용자들을 위한 **자연어 기반 Intent 언어**입니다.

일반 프롬프트는 “설명”이고,
**AILO-H는 AI가 바로 실행할 수 있는 “언어”**입니다.

* 사람에게는 자연스러운 한국어 문장처럼 보이지만,
* AI에게는 완전한 형식 언어(Intent Syntax)로 이해됩니다.

즉,

> **“자연어처럼 쓰고, 프로그래밍 언어처럼 실행되는 한국어 Intent 언어.”**

---

## 🔥 왜 AILO-H인가?

### ✅ 1) 자연어 + 구조의 결합

프롬프트는 해석이 필요하지만,
AILO-H는 **정확한 구조**로 Intent를 전달합니다.

### ✅ 2) 한국어 동사가 그대로 Verb

예:

```
분석하라{ 내용:"시장 붕괴", 기준:"원인→결과" }?
요약해라{ 내용:"논문", 길이:"3문장" }!
철학하라{ 주제:"AI와 인간 공존" }.
```

동사를 사전에 등록할 필요가 없고,
**모든 한국어 동사는 즉시 AILO Verb가 됩니다.**

### ✅ 3) 오해 없는 실행

LLM이 자연어를 “추측”하지 않아도 됨.
Intent = 바로 실행 명령.

### ✅ 4) Prompt Engineering의 종착점

사람은 자연어를 그대로 쓰고,
AI는 Intent로 실행하는 구조.

## 🧩 AILO-H Intent 문법

### ▶ 기본 구조

```
<동사/동사구>{
    <슬롯키>:<값>,
    ...
}<종결기호>
```

### ▶ 종결기호

* `!` 실행(perform)
* `?` 질의(query)
* `.` 서술(describe)

---

## 📝 예시 모음

### 1) 분석

```
분석하라{
  내용:"도구적 공격성",
  기준:["동기","감정","계획성"]
}?
```

### 2) 요약

```
요약해라{
  내용:"보고서 전체",
  길이:"3문장"
}!
```

### 3) 번역

```
번역해줘{
  내용:"It was the kind of rain that forgot how to stop.",
  목표:"ko",
  스타일:{ 톤:"서정", 리듬:"느림" }
}!
```

### 4) 비교

```
비교하라{
  대상A:"적대적 공격성",
  대상B:"도구적 공격성",
  기준:["감정","목표","계획성"]
}?
```

### 5) 철학

```
철학하라{
  주제:"AI와 인간 공존",
  관점:["윤리","진화","문명"]
}.
```

## ⚙ Runtime (E 버전과 동일)

AILO-H는 **AILO v0.9E++**의 런타임 구조를 그대로 사용합니다.

* Parse → Plan → Execute → Validate → Trace
* SRM/FID 기반 검증
* 해시체인 기반 Trace
* 단기/장기/반사 기억 시스템
* strict/secure Validation profile

즉,

> **문법은 한국어지만, 내부 엔진은 글로벌 AILO Core와 완전히 호환됩니다.**

## 🧱 디자인 철학

1. **사람 중심 언어**

   * 누구나 한국어로 Intent 작성 가능

2. **사전 없는 Verb**

   * “동작:” 없음 → 자연어 동사 그대로 Verb

3. **무한 확장성**

   * 미래 개념·철학·프레임을 동사화해서 바로 사용

4. **Prompt → Intent 언어로의 진화**
