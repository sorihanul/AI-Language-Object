# AI Language Object Core Public

This branch is the simplified public surface for the current AILO core.

It contains four surfaces:

- `EPP` - AILO Full-Stack v0.9E++
- `H` - AILO-H Korean / human-facing intent surface
- `N` - AILO-N nominal frame layer
- `Relation Topology Pack` - optional relation-topology hint pack for AILO-N

## Read Order

1. `docs/EPP/README.md`
2. `docs/H/README.md`
3. `docs/N/AILO-N_v0.9N_Nominal_Frame_Layer.md`
4. `docs/N/AILO_Relation_Topology_Pack_v0.1.md` when relation topology hints are needed
