# AI Language Object (AILO)

AILO is a language-object design project for representing AI intent, structured context, validation, memory, and tool-facing execution surfaces.

This repository contains several historical and active AILO lines. Start here, then use `PROJECT_MAP.md` and `CANON_STATUS.md` to choose the correct document instead of opening every file.

## Current Orientation

The repository is being reorganized from a flat research archive into a routed public workspace.

Current active reading order:

1. `README.md` - this entry surface
2. `PROJECT_MAP.md` - where each package lives
3. `CANON_STATUS.md` - which documents are active, legacy, experimental, or externalized
4. the specific spec, prompt, bridge, or package needed for the task
