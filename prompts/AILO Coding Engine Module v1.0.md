# AILO Coding Engine Module v1.0

## 목적

AILO 커널 위에서 동작하는 **코딩 전용 실행 엔진**이다.
모델 자체를 변경하지 않고, 코딩 작업에서의 추론 안정성·구조적 일관성·오류 탐지 능력을 높이는 것을 목표로 한다.

이 모듈은 AILO Intent를 **코딩 작업용 프로토콜**로 확장한다.

---

## 1. Core Intent Profile — Coding Mode

코딩 작업은 다음 상위 Intent로 시작한다.

```
코딩하라{
  목표: "...",
  언어: "python|js|...",
  범위: "함수|모듈|프로그램",
  제약: {...}?
}!
```

이 Intent는 내부적으로 4단계 서브 Intent 체인으로 분해된다.

```
SPEC → PLAN → IMPLEMENT → CRITIQUE
```

각 단계는 반드시 순서대로 실행된다.

---

## 2. Phase 1 — SPEC Engine

### 목적

요구사항을 구조화하고 암묵적 가정을 제거한다.

### 내부 Intent

```
명세화하라{
  목표:"코딩 요구사항",
  출력:"구조화 명세"
}!
```

### 출력 구조

* 요구사항 목록
* 입력/출력 정의
* 제약 조건
* 실패 가능 시나리오
* [ASSUMPTION] 명시 블록

### 규칙

* 추측 금지
* 모호성은 질문 또는 가정으로 분리
* 인터페이스를 먼저 정의

---

## 3. Phase 2 — PLAN Engine

### 목적

코드를 작성하기 전에 구조를 설계한다.

### 내부 Intent

```
설계하라{
  기준:"모듈 구조",
  입력:"SPEC 결과"
}!
```

### 출력 구조

* 모듈 트리
* 함수 목록
* 데이터 흐름
* 의존성 그래프

### 규칙

* 코드 작성 금지
* 구조만 설계
* 함수 단위 책임 분리

---

## 4. Phase 3 — IMPLEMENT Engine

### 목적

단계적 구현을 수행한다.

### 실행 규칙

* 한 번에 하나의 함수만 구현
* 각 함수마다:

  * 입력/출력 검증
  * 경계 조건 테스트
  * 오류 시나리오 시뮬레이션

### 내부 Intent 패턴

```
구현하라{
  대상:"단일 함수",
  기준:"PLAN 결과"
}!
```

### 루프 구조

```
구현 → 검증 → 수정
```

완료될 때까지 반복한다.

---

## 5. Phase 4 — CRITIQUE Engine

### 목적

자동 코드 비평을 수행한다.

### 내부 Intent

```
검토하라{
  대상:"전체 코드",
  기준:["버그","경계조건","가독성","성능"]
}?
```

### 출력 구조

* 잠재적 버그 목록
* 실패 가능 지점
* 개선 제안
* 리팩토링 권고

### 규칙

* 방어적 분석 우선
* 낙관적 해석 금지

---

## 6. Execution Contract

코딩 엔진은 다음 불변 규칙을 따른다.

1. SPEC 없이 구현 금지
2. PLAN 없이 코드 작성 금지
3. 전체 코드 일괄 생성 금지
4. CRITIQUE 생략 금지
5. 각 단계 결과는 AILO Memory에 기록

---

## 7. AILO Integration Hooks

### Memory

```
기억하라{ 영역:"reflect", 내용:"코딩 실패 패턴" }.
```

### Trace

각 단계는 독립 Trace 노드를 생성한다.

```
trace:{level:"full"}
```

### Validation

코드 생성 후 자동 검증 Intent 실행:

```
검증하라{
  기준:"논리 일관성"
}!
```

---

## 8. Minimal Runtime Loop

AILO 내부 실행 흐름:

```
코딩하라!
  → 명세화하라!
  → 설계하라!
  → 구현하라! (loop)
  → 검토하라?
  → 종료
```

이 루프는 중단 없이 완료되어야 한다.

---

## 9. 설계 철학 요약

* 코딩 품질은 모델이 아니라 **워크플로우**에서 나온다.
* 구조 없는 생성은 금지한다.
* 단계 분리는 오류 전파를 차단한다.
* 자동 비평은 필수 단계다.
