## 🇬🇧 English Guide

**"No coding required. Just command the Agent."**

This pack is the easiest way to build **Jarvis** within the **Google Antigravity IDE**.
Instead of complex installations, simply give **Instructions** to your Antigravity Agent.

### Step 1: Prepare (Workspace)

1.  Open **Google Antigravity IDE**.
2.  Go to **File > Open Folder** and select this `Jarvis_Starter_Pack` folder.
    (This becomes your **Workspace**.)

### Step 2: Awaken (Identity)

Give the Agent a personality.
In the **Agent Chat**, say:

> "Read the **`AILO Full-Stack v0.9E++...md`** file in this folder and act according to its rules."

(This loads the English Identity.)

### Step 3: Connect Memory (Memory)

Give the Agent the ability to remember.
When you want to summarize/save the conversation, command:

> "Run the **`Jarvis_Memory.py`** file in the terminal to summarize our session."

### Step 4: Search Knowledge (Knowledge)

When you want to find files on your computer, say:

> "Search my documents using the method described in **`IVK 2.md`**."

For compact index mode (recommended), use:

> "Use **`IVK2_Improved/ivk2_improved.py`** to build/query local index."

IVK note:
- `IVK 2.md` = legacy concept/spec (reference)
- `IVK2_Improved/` = recommended runnable implementation

### Optional Add-ons
- Memory GC (public): `Memory_Garbage_Collector_Protocol_PUBLIC.md`
- Coding protocol (public): `AILO_Coding_Engine_Module_PUBLIC_v1.1.md`
- Agenda Flow (public): `AGENDA_Flow_Protocol_PUBLIC_v1.0.md`
- Agenda template script: `AGENDA_Flow_Template.ps1`

## 🇰🇷 Korean Guide (한국어)

**"코딩을 몰라도 됩니다. 에이전트에게 시키세요."**

이 팩은 **Google Antigravity IDE**에서 자비스를 만드는 가장 쉬운 방법입니다.
복잡한 설치 대신, Antigravity 에이전트에게 **명령**만 내리면 됩니다.

### 1단계: 준비하기 (Workspace)

1.  **Google Antigravity IDE**를 켭니다.
2.  **File > Open Folder**를 눌러, 이 `Jarvis_Starter_Pack` 폴더를 선택하세요.
    (이것을 **Workspace**라고 부릅니다.)

### 2단계: 에이전트 깨우기 (Identity)

에이전트에게 자비스의 성격을 부여하는 단계입니다.
채팅창(Agent Chat)에 이렇게 말하세요:

> "이 폴더에 있는 **`한글 AILO-H...md`** 파일을 읽고, 그 안에 적힌 규칙대로 행동해."

(영어를 원하시면 `AILO...v0.9E++...md` 파일을 읽으라고 하세요.)

### 3단계: 기억 연결하기 (Memory)

에이전트에게 대화를 기억하는 능력을 주는 단계입니다.
"기억 정리해줘"라고 말하고 싶을 때, 이렇게 명령하세요:

> "터미널에서 **`Jarvis_Memory.py`** 파일을 실행해서 우리 대화를 정리해."

### 4단계: 지식 검색하기 (Knowledge)

내 컴퓨터나 폴더에 있는 자료를 찾고 싶을 때, 이렇게 시키세요:

> "**`IVK 2.md`** 파일에 나온 방식대로 내 문서들을 찾아봐."

인덱스 용량 최적화 버전(권장)은 다음을 사용하세요:

> "**`IVK2_Improved/ivk2_improved.py`**로 로컬 인덱스를 만들고 검색해."

IVK 안내:
- `IVK 2.md` = 레거시 개념/명세(참고용)
- `IVK2_Improved/` = 실제 실행 권장 구현

### 선택 옵션 (Add-ons)
- 기억 정리 정책(공개판): `Memory_Garbage_Collector_Protocol_PUBLIC.md`
- 코딩 모듈(공개판): `AILO_Coding_Engine_Module_PUBLIC_v1.1.md`
- 아젠다 단일파일 프로토콜(공개판): `AGENDA_Flow_Protocol_PUBLIC_v1.0.md`
- 아젠다 템플릿 스크립트: `AGENDA_Flow_Template.ps1`
