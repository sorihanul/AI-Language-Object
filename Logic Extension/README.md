# AILO Core v0.9 (Logic Edition)

## 🧭 Overview
**AILO Core v0.9 (Logic Edition)** is a minimal open framework  
based on the original AILO foundation, now with a lightweight logic layer  
for clearer reasoning and interpretability.  
It is intended for general testing, conceptual exploration, and educational use.

---

## ⚙️ Main Features
- **Logic Extension:** Adds basic proof and reasoning capability  
- **Belief Update Model:** Adapts to unexpected or inconsistent outcomes  
- **Lightweight Design:** Simple, modular, and easy to understand  
- **Open License:** Free to modify, reuse, or integrate into other projects
